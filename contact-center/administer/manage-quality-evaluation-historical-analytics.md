# Manage the quality evaluation historical analytics dashboard

Enable the quality evaluation historical analytics dashboard to help supervisors track agent performance trends over time.

## Prerequisites

You must have the Administrator role.

## Enable quality evaluation historical analytics

To enable the dashboard:

1. In Customer Service admin center, go to **Insights**.
1. Under **Quality evaluation agent analytics**, select **Manage**.
1. Turn on the **Enable Quality Evaluation Agent historical Analytics** toggle.
