During preview, you can't change every setting in Contact Center Admin Workspace. Create and edit capacity profiles, skills, operating hours, channel setup, and other shared settings in the Copilot Service admin center. When Contact Center Admin Workspace uses one of these settings, such as a queue's operating hours, you can select an existing record, and a link opens it in Copilot Service admin center in a new tab.
